轻量 · 优雅 · 高效

本兼容分支：[`4o4E/lite-tools` 的 `compat/qq-9.9.36`](https://github.com/4o4E/lite-tools/tree/compat/qq-9.9.36)，上游为 [`xiyuesaves/lite-tools`](https://github.com/xiyuesaves/lite-tools)。

## 安装方法

### 从 Releases 安装

- 下载 [Releases](https://github.com/xiyuesaves/LiteLoaderQQNT-lite_tools/releases) 中对应版本的压缩包
- 将压缩包内容解压到加载器数据目录下的 `plugins/lite-tools` 文件夹
- 重启 QQ 后，在插件设置中启用并配置

当前构建产物文件名格式为 `lite-tools v<version>.zip`。

### 手动构建

```bash
git clone --branch compat/qq-9.9.36 https://github.com/4o4E/lite-tools.git
cd lite-tools
pnpm install
pnpm run build:alpha
```

`build:alpha` 使用 `package.json` 中的版本号，无需为本地兼容构建创建 Git tag。正式版本的 `build` 仍要求当前提交有版本 tag。

## 使用说明

- 打开设置，进入 `轻量工具箱`
- 大部分功能在设置页内直接开关或填写参数即可
- 标注了“重载消息生效”或“重启生效”的选项，需要额外刷新对应界面
- `顶部功能栏` 和 `聊天功能栏` 需要先进入一次对应界面，设置页才会自动读取并显示可精简的项目
- `消息相关 → 点击群昵称 @` 为独立开关，默认开启。点击群聊消息的他人昵称调用 QQ 原生 `@` 菜单项，只插入输入框、不自动发送；关闭或重新开启对已显示消息立即生效，关闭后恢复原生昵称提示和点击行为。
- `消息相关 → 原生接口戳一戳（Windows）` 为独立开关，默认关闭。开启后接管聊天消息头像双击和原有头像右键菜单中的“戳一戳”，直接调用 Windows QQ 内核 `sendNudge`；开关立即生效，单击头像查看资料不变。不新增缺失的原生菜单项，也不强制启用原生禁用项。
- 原生戳一戳模式仅绕过这两个入口的前端发送逻辑，不解除账号权限、每日次数或服务端频控。内核拒绝时显示结果码及原始错误，不自动重试、排队或回退再发；切换会话、复用消息节点或发送者变化时取消旧菜单动作。
- `消息+1 → +1 显示位置` 只提供 `消息悬浮` 和 `消息右键` 两种互斥方式，默认 `消息右键`。切换后更新已挂载消息，不必重开会话；总开关同时控制两种入口。
- 悬浮和右键 `+1` 共用完整复读逻辑：含 `@` 或回复引用时，按旧版修改过的实现克隆原始消息元素并调用 `sendMsg`，保留提及身份、回复目标及混合内容，仅清除待发送元素自身的旧 ID；不重新拼接纯文本，也不修改收到的消息。普通图文继续走 QQ 原生转发。
- `+1` 的完整发送和普通转发均使用 QQ 为当前账号、当前会话生成的原生发送属性，保留自己正在使用的气泡等装扮，不复制原消息发送者的装扮。原生属性不可用时取消复读并记录错误，不退回空属性或纯文本发送；等待属性期间关闭功能、切换会话或消息失效时也会取消。
- `消息右键` 只在消息内容菜单显示 `+1`，不在头像、昵称或昵称时间的菜单显示。菜单单击执行复读；`双击执行` 仅用于悬浮按钮。
- 右键 `+1` 使用 QQ 原生菜单的图标头、图标和文字容器，混合菜单中与原生菜单项对齐，不额外叠加文字缩进。
- 只有 QQ 表情的纯表情消息同样支持 `+1`，与文本、图片、商城表情消息共用同一套复读判断。
- `消息相关 → Noto 表情` 为独立开关，默认开启。统一贴表情面板、右键快捷界面、消息回应、输入框和已发送消息中的 emoji 为 Google Noto 样式；关闭后不再注入字体和替换逻辑，需重启生效。
- 原 QQ `贴表情` 面板的 `emoji 表情` 分区由 `ctx.panelEmojis` 渲染，完整协议列表在 `props.emojis`；插件只补 DOM 缺失项，不新建菜单或面板，也不改变原面板的点击与提交逻辑。
- 面板 `emoji 表情` 分区原生 `ctx.panelEmojis` 为 146 项，`props.emojis` 为 165 项完整协议列表；插件把缺失的 19 项补进 DOM，点击调用原生 `onClickSticker`，不改面板自身数据。
- 系统表情分区保持客户端原有列表，不强行加入隐藏或协议未允许的系统表情。
- `emoji 表情` 分区统一改用 Google Noto Emoji 的 128px PNG，图片以 data URL 内联在 `notoEmoji.json`，不依赖 CDN 或本地 `appimg://`；原有 68 项和补充项都替换为 Noto 图标，系统表情分区仍使用 QQ 本地资源。
- `最近表情`（面板第一分区）和右键菜单里的 emoji 图片同样替换为 Noto；面板和快捷界面中的文本 emoji 按原文本实际尺寸生成图片，系统表情图片不受影响。
- 右键直接打开的快捷贴表情界面：图片按 `EmojiSystermResource` 路径识别并替换；文本 emoji 在 `.q-context-menu`、`[class*=reaction]`、`[class*=express]` 容器内替换为 Noto。
- 输入框和已发送消息中的 emoji 文本通过覆盖 QQ 的 `"Color Emoji"` 字体族使用 Noto Color Emoji，字体来自 jsDelivr CDN，只匹配 emoji 的 unicode-range，不影响普通文字。
- 消息上的表情回应项（`reaction-item-expression-emoji`）从文本替换为 18×18 的 Noto 图片，保持原 span 的 18×18 占位；协议表内的 emoji 用内联图，表外的回退到 Noto CDN。回应计数和点击逻辑不变。
- 只补协议表内允许的表情；不加入隐藏的多段超级表情、商城表情或协议表外的 emoji。协议表中的猪是 `🐷 /猪`（qcid 128055）；`🐖` 不在协议表内，加入菜单后服务端不会生成回应，因此不再补充。
- `显示消息发送时间 → 插入到用户名后方` 保留昵称后时间显示，不占用气泡插槽。
- `界面调整 → 阻止消息窗口拖拽操作` 仅拦截单独按住左键的空白区拖动；中键、前后侧键及带侧键的组合均保留原生事件。消息内容选择、滚动条拖动不受影响。侧键最终触发何种动作仍由 QQ 原生逻辑及“侧键返回主列表”开关决定，本功能不模拟左键。
- `界面调整 → 图片缩放增强` 为独立开关，默认关闭，不依赖“图片查看器优化”。开启后隐藏图片中央的缩放比例提示，保留底部工具栏；调整窗口尺寸时保持当前图片的实际显示比例。打开、切换图片由 QQ 原生加载流程直接完成窗口适配（保留原始尺寸上限和长图规则）；手动开启此功能时适配已显示的图片。关闭后恢复原生提示及后续窗口自适应行为，不强制重置当前比例。

## 功能列表

### 界面调整

- 图片查看器优化
- 图片缩放增强（独立开关：隐藏中央提示、窗口调整保持缩放、打开时自适应）
- 侧键返回主列表
- 阻止消息窗口拖拽操作（仅左键，保留中键和侧键）
- 删除消息气泡装扮
- 隐藏天气按钮
- 隐藏经典模式切换按钮
- 隐藏锁定按钮
- 隐藏退出账号按钮
- 隐藏检查更新按钮和更新通知
- 隐藏 VIP 彩色昵称

### 消息相关

- 移除回复 `@`
- 替换小程序卡片为网页卡片
- 解除商城表情限制
- 消息 `+1`：悬浮按钮 / 消息右键菜单二选一
- 悬浮 `+1` 双击执行
- 消息右键 `贴表情`：补回客户端过滤的协议表情
- 显示每条消息发送时间，可放在用户名后方
- 显示时区
- 自定义时间格式
- 自定义日期格式

### 阻止撤回

- 拦截撤回消息
- 可选拦截自己的撤回操作
- 持久化保存撤回记录
- 重定向撤回图片保存路径
- 查看重定向图片目录
- 自定义撤回提示颜色
- 清理本地撤回缓存
- 查看撤回消息列表

### 本地贴纸

- 启用本地贴纸面板
- 选择贴纸目录
- 将入口移动到左侧
- 拖拽排序贴纸集
- 以图片形式发送贴纸
- 调整每行贴纸数量
- 调整面板宽度和高度
- 下载 Telegram 贴纸
- 配置 Telegram Bot Token
- 配置 `ffmpeg` 路径
- 配置 `tgsToGif` 路径
- 配置 HTTP 代理并检测可用性

### 自定义背景

- 使用单张图片或视频作为背景
- 去除背景遮罩
- 调整媒体透明度
- 调整前景容器透明度
- 分别为联系人列表、群成员区、消息气泡、输入框启用磨砂效果

### 精简功能

#### 侧边栏

- 可分别控制顶部和底部侧边栏项目显隐
- 默认可管理的项目包括：`消息`、`联系人`、`更多`、`调色盘`、`邮箱`、`文件管理器`、`收藏`、`我的手机`
- 侧边栏中的 `更多` 项通常包含设置入口，关闭前请确认你还有其他方式打开设置页

#### 顶部功能栏

- 首次进入群聊或私聊界面后，插件会自动读取当前可见栏目
- 之后可在设置页中逐项精简显示

#### 聊天功能栏

- 首次进入群聊或私聊界面后，插件会自动读取当前可见栏目
- 之后可在设置页中逐项精简显示
